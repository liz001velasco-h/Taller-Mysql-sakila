# Taller 2 - SQL Sakila

Este repositorio contiene el desarrollo del taller práctico de SQL utilizando la base de datos Sakila en MySQL.

## Contenido
- Consultas básicas (SELECT, WHERE)
- Ordenamiento de datos (ORDER BY)
- Relaciones entre tablas (INNER JOIN, LEFT JOIN)
- Manipulación de datos (INSERT, UPDATE, DELETE)
- Consultas avanzadas (GROUP BY, funciones de agregación)

## Base de datos
Se utilizó la base de datos Sakila, que simula un sistema de alquiler de películas con múltiples tablas relacionadas.
